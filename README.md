# Escribanía de la Compañía

Generador de pergaminos para la Compañía: bandos, cartas, contratos, órdenes y los documentos del Libro de las Minas (pago, incidencia y declaración), con el escudo y el sello, en español, inglés, portugués y polaco.

Ábrelo en el navegador, rellena el formulario y descarga el PNG o copia el texto para Discord.
